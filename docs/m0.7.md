# M0.7 — Simple Java-like type system

Raz now has a small nominal primitive type family inspired by Java, without attempting Java's object model.

Supported source types:

- `int`
- `long`
- `float`
- `double`
- `bool` and alias `boolean`
- `char`
- `string` and alias `String`
- `void` for function returns only

Decimal literals are `double`, matching Java's default floating-point literal behavior; an `f` suffix such as `1.5f` creates a `float` literal. Assignment allows only widening numeric conversions (`char -> int -> long -> float -> double`); narrowing is rejected.

`let` may still infer a local type when the annotation is omitted.
