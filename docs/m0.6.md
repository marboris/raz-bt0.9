# Raz 2 — M0.6

M0.6 adds package-aware module resolution and the first standard-library layout.

## Package manifest

Each Raz package may contain a `raz.json` manifest:

```json
{
  "name": "package_app",
  "version": "0.1.0",
  "stdlib": "stdlib",
  "source_roots": ["src"],
  "dependencies": {
    "demo": "../demo"
  }
}
```

Fields:

- `name`: package name used for qualified dependency modules.
- `version`: package version metadata.
- `stdlib`: project-local standard library root.
- `source_roots`: directories searched by `src:` includes.
- `dependencies`: local package directory mappings.

No network package fetching is implemented yet. M0.6 intentionally uses reproducible local paths.

## Include forms

The existing relative form remains:

```raz
include("lib/math.ro");
```

M0.6 adds:

```raz
include("std:math.ro");
include("pkg:demo/math.ro");
include("src:math.ro");
```

Standard library modules are qualified as `std::module::function(...)`. Dependency modules are qualified as `package::module::function(...)`.

## Standard library

The first checked-in stdlib module is `stdlib/math.ro`.

The compiler does not special-case the contents of the standard library: stdlib code uses the same Raz parser, AST, semantic analyzer, and C++ code generator as application modules.
