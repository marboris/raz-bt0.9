# M0.8 — Collections

Raz provides three parameterized runtime collection types backed by the C++ standard library:

- `List<T>` → `std::vector<T>`
- `Map<K,V>` → `std::map<K,V>`
- `Set<T>` → `std::set<T>`

Examples:

```raz
let xs: List<int> = [1, 2, 3];
xs.add(4);
echo(xs.get(1));
echo(xs.size());

let prices: Map<String, double> = {"cpu": 3.5};
prices.put("gpu", 5);
echo(prices.get("gpu"));

let tags: Set<int> = new Set<int>();
tags.add(10);
```

Empty literals require an explicit generic type. The initial collection API intentionally stays small: construction, `add`/`put`, `get`, `size`, `contains`, indexing, and set `remove`.
