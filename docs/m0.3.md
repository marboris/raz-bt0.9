# Raz 2 — M0.3

M0.3 extends the bootstrap compiler with the first useful control-flow and static type checks.

## Supported syntax

```raz
function add(a: int, b: double) -> double {
    return a + b;
}

function main() {
    let x: int = 0;

    if (x == 0) {
        echo("zero");
    } else {
        echo("non-zero");
    }

    while (x < 3) {
        x = x + 1;
    }

    for (let i: int = 0; i < 3; i = i + 1) {
        echo(i);
    }
}
```

The milestone adds:

- `if / else if / else`
- `while`
- C-style `for`
- assignment statements
- unary `+`, `-`, `!`
- `&&`, `||`, `==`, `!=`, `<`, `<=`, `>`, `>=`
- optional variable annotations (`let x: int = ...`)
- optional parameter annotations (`x: int`)
- optional function return annotations (`-> int`)
- primitive type checking for `int`, `float` (mapped to C++ `double`), `string`, `bool`, `void`, and `auto`
- lexical block scope with controlled shadowing
- function argument type validation

## Deliberate limits

M0.3 does not yet implement modulo, bitwise operators, `break`, `continue`, collections, user-defined types, generics, or recursive-function prototype emission.

`async/await`, Core methods/macros, and the package/stdlib system remain later milestones.
