# M0.9 — Module visibility decision

No new compiler feature is required for M0.9. Raz uses whole-file includes:

```raz
include("lib.ro");

function main() {
    echo(lib::visible());
}

main();
```

Every function declared in an included file is public through that module's namespace. There is intentionally no `private`, `export`, or `re-export` mechanism in this milestone. Adding such a layer would be extra surface area without solving a requirement in the current design.
